# Chalk Dotted Line Trick

IYPT 2027 第12题「Dotted line trick」的研究资料与实验记录。

项目条件：两人协作、三个月、人民币500元预算；先进行预实验，再确定正式实验参数。

## 阅读顺序

1. [文献研究综述](01_文献研究综述.md)：相关研究、来源与证据局限。
2. [理论推导](02_理论推导.md)：黏滑、结构振动与离板模型，以及待验证预测。
3. [实验方案](03_实验方案_两人三个月500元.md)：预实验、校准、实验矩阵、分工与预算。

当前文件属于研究准备材料，不包含本项目已完成实验的结论。

## 实验资料归档

- `data/raw/YYYYMMDD/`：本地保存原始录像和照片。
- `data/calibration/`：标尺、预载、刚度和自由振动标定。
- `data/processed/`：处理后的轨迹及统计结果。
- `analysis/`：分析代码及可复现步骤。
- `figures/`：用于报告的图表。
- `logs/`：操作卡、失败记录与支出台账。

上述目录按需要创建。原始视频和文献下载缓存默认不进入 Git；共享大文件时，在实验日志中记录保存位置和对应的实验编号。需要纳入仓库的代表性照片可放在 `figures/`。

## 两人协作

开始工作前，在工作区没有未提交修改时运行：

```bash
git pull --ff-only
```

每次围绕一项明确改动提交。添加文件时写出具体文件名，检查暂存内容后再提交和推送：

```bash
git diff --cached
git commit -m "说明本次改动"
git push
```

若同步提示分支分叉或冲突，保留双方内容后处理，不使用强制推送覆盖队友的提交。复杂改动可使用分支和 Pull Request。

记录实验时保留唯一 `run_id`、原始数据位置、装置设置和异常原因。文献结论、理论预测与实测结果分别标明。
